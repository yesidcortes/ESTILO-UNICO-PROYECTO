# Estilo Único - Plataforma E-commerce Full-Stack
**Estilo Único** es una plataforma de comercio electrónico desarrollada con arquitectura full-stack, integrada con autenticación de usuarios, catálogo de productos y gestión de base de datos híbrida (MongoDB y SQL).
---
## 🛠️ Tecnologías Utilizadas
- **Frontend:** React, HTML5, CSS3, JavaScript (ES6+).
- **Backend:** Node.js, Express.js.
- **Bases de Datos:** MongoDB (NoSQL) y MySQL (SQL).
- **Herramientas:** Git, VS Code, Figma, Postman.
